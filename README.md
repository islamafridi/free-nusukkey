## What is NusukKey?

[NusukKey](https://nusukkey.com/) is an independent community website where participants in the Nusuk Free Umrah Competition can copy invite codes (they start with `NG-`) shared by other people, and share their own.

Copying a code from NusukKey and entering it in the Keys area of the Nusuk app can earn extra keys for you and for the person who shared it. The competition itself runs only inside the official Nusuk app, and winners are chosen by Nusuk under its own terms.

> **Disclaimer:** NusukKey is not affiliated with Nusuk or the Saudi Ministry of Hajj and Umrah. Codes listed on the site are shared by the community, and only the Nusuk app can confirm whether a code is accepted.

## Features

| Feature | What it does |
| --- | --- |
| Fair rotation | Fresh codes get shown instead of the same few staying on top |
| One-tap copy | Copy a code and paste it into the Nusuk app |
| Open in Nusuk | A deep link opens the official Nusuk service with the code filled in |
| Problem reports | Report a code that Nusuk rejects; codes with two independent reports are removed from rotation |
| On-device history | Codes you copied are tracked locally in your browser |
| English and Arabic | Bilingual interface, installable as a PWA |

## How to use a code

1. Install or update the [Nusuk app](https://nusuk.sa) (iOS, Android, or web) and set up your account.
2. Open [nusukkey.com](https://nusukkey.com/) and copy a code that starts with `NG-`.
3. In the Nusuk app, go to the Free Umrah Competition, open **Keys**, and paste the code.
4. If the app rejects the code, report it on [NusukKey](https://nusukkey.com/) so it stops being shown.
5. Add your own invite code to [NusukKey](https://nusukkey.com/) so others can use it.

## Safety

- **Never share your Nusuk password or SMS one-time codes.** An invite code is only the short `NG-` string.
- Enter codes only in the official Nusuk app or at [nusuk.sa](https://nusuk.sa).
- Extra keys are extra chances, not a guarantee of winning.
- Do not pay anyone for codes or for a promised win.

## FAQ

**Is NusukKey free?**
Yes. Copying and sharing codes costs nothing. See [nusukkey.com](https://nusukkey.com/).

**Why was my code rejected?**
It may have reached its limit, you may have used it already, or it may have been mistyped. Try another code and report the bad one.

**Is this the official Nusuk site?**
No. The official platform is [nusuk.sa](https://nusuk.sa), run by the Ministry of Hajj and Umrah.
